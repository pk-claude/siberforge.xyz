Methodology

  • Fundamentals: SEC EDGAR XBRL companyfacts. Annual history from 10-K filings (up to ~19 years); standalone quarters rebuilt by differencing YTD 10-Q filings; restatements resolved to the latest filing vintage. Yahoo Finance fills recent quarters, foreign filers, and market data.
  • Valuation lab: reverse DCF (what growth is priced in), scenario DCF with fading growth, and a revenue-path mode for pre-FCF names. Presets tie to the written bear/base/bull scenarios; every input is draggable.
  • Peer comps: live multiples for a hand-picked peer group per name, refreshed with the same pipeline, USD-normalized.
  • Research layer: thesis, moat, risks, catalysts, and what's-priced-in, written per name with dated sources. Each page shows its as-of date — ask for a refresh after earnings.
Data: SEC EDGAR XBRL filings + Yahoo Finance. Not investment advice. 2026
